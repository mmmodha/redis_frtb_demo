Speaker notes: 1. OSS is single-threaded, no Auto Tiering, no Active-Active, no Operator. Free is not the same as fit-for-purpose. 2. ClickHouse / Snowflake are analytical, not operational. Wrong layer. 3. KV stores (Aerospike, Scylla, DynamoDB) cannot host the JSON shape with in-database compute. 4. KDB is cost, talent scarcity, lock-in. Right answer for 2010 tick capture, wrong answer for 2026 FRTB JSON. 5. Oracle + Spark is the incumbent — augment it, don't rip-and-replace.
