## Single named hypothesis for Wave 5.15b

**`bootstrap-wiring`** — `services/api/src/index.ts` is missing the import
of `markBootstrapReady`, `markBootstrapFailed`, and `markBootstrapSkipped`
from `./server.ts`. The Wave 5.14b.1 source-side change exported these
functions and added call sites at index.ts lines 101, 111, 121, 126, but
never updated the import block (line 12 only imports `createServer`).

The fix is a one-line addition to the existing
`import { createServer } from "./server.ts";` — making it
`import { createServer, markBootstrapReady, markBootstrapFailed, markBootstrapSkipped } from "./server.ts";`.

Until that's in, every fresh build of the api image will crash-loop and
every smoke run will RED-out at step 2.5.
