## Wave 5.14 candidates (concrete root-cause hypotheses)

1. **Per-variant TAG search returns 0 despite num_docs=32,666** — primary blocker.
   - Hypothesis A: `idx:sens` schema tag attributes are CASESENSITIVE while
     payload writes UPPERCASE `DELTA/VEGA` but API queries lowercase `delta/vega`
     (or vice versa). Verify by dumping `FT.INFO idx:sens` schema attrs +
     a known sens:* doc shape.
   - Hypothesis B: FT.SEARCH not fanning out across both shards from
     the API's redis client; coordinator routing missing. Verify by running
     same FT.SEARCH from inside the api container (cluster-aware client).
   - Hypothesis C: Index name visibility mismatch — bootstrap created on both
     nodes but proxy routes FT.SEARCH to single shard.

2. **Generator CMD-arg passthrough broken** — `docker compose run --rm generator
   --rows 2000000 --classes girr,equity,fx` lands as `node --rows ...`.
   Move the generator entry into a dedicated script that consumes its own argv,
   or move all knobs to env vars.

3. **Loadgen SSE stream paths absent** — `/loadgen/metrics/stream`,
   `/loadgen/events`, `/loadgen/summary` all 404. Document the actual
   final-summary endpoint (only `/loadgen/status` works) or wire SSE.

4. **E2e step 02a renders no `demo-cluster` text in UI** — `/connections` API
   returns both clusters, but the `Connections` page doesn't surface them.
